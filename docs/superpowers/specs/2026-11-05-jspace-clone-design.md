# QSpace 复刻设计（j-ui）

日期：2026-11-05
状态：已获用户批准的设计，待生成实施计划

## 1. 背景与目标

用 j-ui 框架复刻 macOS 文件管理器 QSpace 的核心外观与交互：多面板工作区、
每面板多标签、面包屑导航、列表/图标两种视图、侧栏、系统设置风格的偏好窗口。
数据源为真实文件系统（java.nio.file），支持安全的文件操作。

视觉参照三张 QSpace 截图：

- 主窗口（深色）：2×2 四面板 + 左侧栏（暂存架/书签/iCloud/服务器/访达标签/工作区 + 底部过滤框），
  每面板顶部胶囊标签栏（+ 新建）与面包屑路径栏，激活面板蓝色描边、路径栏蓝底；
  列表四列（名称/修改日期/大小/种类），文件夹 ▸/▾ 树形展开，按类型的彩色图标，选中行半透明蓝高亮。
- 设置窗口：macOS 系统设置风格——左侧搜索框 + 彩色贴片图标导航列表（选中蓝色圆角高亮块），
  右侧分组圆角卡片，内含 iOS 风格开关、复选框、下拉、橙色警示文字。
- 第二张主窗口：同一 2×2，两个面板列表视图、两个图标网格视图（蓝紫渐变文件夹图标），
  即每个面板可独立选择视图模式。

用户决策（2026-11-05）：

| 决策点 | 选择 |
|---|---|
| 数据源 | 真实文件系统（java.nio） |
| 文件操作 | 浏览 + 安全操作（新建文件夹、重命名、删除、复制/剪切/粘贴） |
| 窗口范围 | 主窗口 + 设置窗口 |
| 面板布局 | 1 / 2 / 2×2 三档，可切换、可拖动分割线 |
| 主题 | 跟随系统明暗 + 可在设置中切换 |
| 设置窗口 | 导航列表做全，通用页 8 项真实生效，其余页占位 |
| 平台 | 仅 macOS |
| 实现方案 | 给框架补 `splitVertical`（方案 A） |
| 代码位置 | 独立 `jui/jspace` 包（先例 `jui/sevenwdb`） |

## 2. 范围

### 2.1 主窗口

- 默认 1280×800，最小 720×480，标题随当前目录名。
- 布局自上而下：工具栏；主体 = 侧栏(230 DIP，可折叠) + 面板网格；底部状态栏。
- 深浅两套配色，默认跟随系统，设置可切「跟随/浅色/深色」。

### 2.2 面板网格与活动面板

- 三档布局：单面板、左右双面板、2×2（默认，对齐截图）。
- 2×2 = `splitVertical( split(左上, 左下), split(右上, 右下) )`；双面板 = 一个 `split`；单面板直接放。
- 分割线可鼠标拖动、键盘方向键移动（每次 8 DIP），复用框架 split 行为。
- 点击面板内任意处即激活该面板；活动面板 1.5 DIP 强调色描边 + 面包屑栏蓝底高亮。
- 布局切换时尽量保留已有面板及其状态：扩大档位时新增面板初始为主目录（或复制活动面板路径）；
  收缩档位时保留左上侧面板，被丢弃面板的状态直接释放。

### 2.3 面板（FilePane）

- 标签栏：胶囊标签（目录小图标 + 目录名 + × 关闭），「+」新建；
  点击切换、× 关闭；⌘N 新建、⌘W 关当前（关完面板保留一个空标签=主目录）。
  （框架无鼠标中键事件，中键关闭不做。）
- 每标签独立持有：当前路径、返回/前进历史栈、视图模式（列表/图标）、滚动位置、展开的目录集合、排序状态。
- 面包屑：🏠(主目录) + 路径各级，`›` 分隔，点击跳级；显示为活动面板时整条蓝底。
- 重命名：面包屑下方出现内联输入框（textInput），回车提交、Esc 取消。
- 工具栏（全局，作用于活动面板的当前标签）：标题=当前目录名、返回/前进、
  列表/图标分段切换、排序 popover（名称/修改日期/大小/种类 + 升序/降序）、
  布局切换（1/2/2×2）、搜索框（实时过滤当前目录）、设置按钮（打开设置窗口，⌘,）。
- 应用菜单：关于 QSpace、设置…⌘,、新建标签 ⌘N、关闭标签 ⌘W、退出 ⌘Q。
  菜单栏快捷键不在窗口内重复注册（框架规则）。

### 2.4 两种文件视图

**列表视图**（默认）：

- 表头四列：名称（自适应剩余宽）、修改日期(120)、大小(80)、种类(110)。
  点击表头切换排序（再点反转），当前列显示 ∧/∨ 箭头。
- 默认排序：文件夹置顶 + 名称升序；两项都可在设置改。
- 树形展开：文件夹行首 ▸/▾，展开时子目录条目**平铺插入**该文件夹之后（缩进每层 +16 DIP），
  子目录内容按需后台扫描一层；同一标签内展开状态持久于会话。
- 行高 28 DIP（紧凑 24）；图标 20 DIP + 名称截断；选中行半透明蓝底、4 DIP 圆角。
- `Ui.list` 虚拟化 + 变行高 + key(条目路径)；↑↓ 移动选中、↩ 进入/打开、双击同；
  → 展开选中的文件夹（已展开则进入），← 折叠选中的文件夹（已折叠则选中跳到父级）。
- 显示为：名称左对齐，日期/种类左对齐，大小右对齐；文件夹大小显示 `--`。

**图标网格视图**：

- 单元格 96 宽 × 116 高：48 DIP 图标 + 最多两行截断的文字（居中）。
- **行分组虚拟化**：用 `Ui.list` 每行建一个 wrap row，行内项数 N=⌊内容宽/96⌋，
  行号 r 的条目下标 [r·N, (r+1)·N)；行高固定 116，key 用条目下标，保证滚动性能与列表一致。
- 选中：图标加强调色描边 + 文字变强调色；双击进入/打开，↑↓←→ 网格导航。

**共用**：

- 加载中：内容区中央灰色「正在载入…」；空目录：「此文件夹为空」；无权限/不存在：错误提示 + 「返回主目录」按钮。
- 打开文件：`/usr/bin/open <path>`（ProcessBuilder，不在 native image 引 AWT）。

### 2.5 右键菜单（框架 contextMenu）

空白处：新建文件夹、粘贴、排序子菜单（四种键 + 升降）、视图切换子菜单、显示隐藏文件（勾选）、刷新 ⌘R。
条目上：打开、在新标签页中打开（文件夹）、重命名、拷贝 ⌘C、剪切 ⌘X、粘贴 ⌘V（空白处语义）、删除 ⌫。

### 2.6 文件操作（FileOps）

- 全部后台虚拟线程执行，主线程发布结果；操作完成自动刷新受影响的目录快照。
- 新建文件夹：面板内联输入或菜单触发，「未命名文件夹」递增去重。
- 重命名：同目录 `Files.move`。
- 删除：文件 `Files.delete`；目录递归删除。执行前 modal 确认（显示名称与条目数）。
- 复制/剪切/粘贴：应用内剪贴板记录 (来源路径, COPY|MOVE)；⌘V 在当前目录执行
  `Files.copy`（递归）/ `Files.move`（跨面板即移动）。粘贴到自己所在目录时自动追加「副本」后缀。
- 同名冲突：弹一次 modal，作用整批——「覆盖」「跳过」「取消」。
- 失败（权限等）：状态栏红色文字报告，不崩溃。

### 2.7 侧栏

- 分组（上到下）：暂存架（占位分组，v1 无功能）、书签（桌面/下载/文稿/图片/音乐/影片/主目录/应用程序/废纸篓）、
  iCloud（iCloud 云盘，路径存在才显示）、服务器（Macintosh HD = /）、访达标签（静态彩色圆点列表，不联动真实标签）、
  工作区（仅「默认」）。废纸篓 = ~/.Trash。
- 书签用真实英文路径 + 中文显示名；点击 = 活动面板当前标签导航至该位置。
- 底部「过滤」框：按显示名过滤侧栏项。
- 侧栏可整体折叠（工具栏按钮），折叠后只剩 4 DIP 分隔条。

### 2.8 状态栏

左侧：当前面板「N 项 · 已选 1 项（约 xx MB）」；右侧：临时提示/错误（5 秒淡出）。

## 3. 文件系统层（store）

### 3.1 FileStore

- 每次导航：主线程立刻发布「加载中」快照 → 后台虚拟线程 `Files.readDirectoryAttributes`
  扫描（照抄 notes-vault 的后台→主线程发布模式）→ 发布不可变 `FileEntry[]`。
- `FileEntry`：name、path、isDirectory、sizeBytes(-1 为目录)、lastModified、kind(中文种类)、iconType、hidden。
- 过滤：搜索词（名称包含，不区分大小写）、隐藏文件（设置项，`.` 前缀或 `Files.isHidden`）。
- 排序：文件夹置顶（可关）+ 键（名称本地化比较/修改日期/大小/种类）+ 方向。
- 相对日期：今天 HH:mm / 昨天 HH:mm / 今年 M/d HH:mm /往年 yyyy/M/d HH:mm。
- 种类映射：常见扩展名 → 中文（磁盘映像/Android 应用程序/文件夹/PDF 文稿/PNG 图像/MPEG-4 影片/
  ZIP 归档/RAR 归档/GL 传输格式/Word 文稿/源代码/纯文本…），未知回退「文档」；无扩展名且目录=「文件夹」。
- 扫描带代数(generation)，过期结果丢弃；同一标签快速连续导航不阻塞 UI。

### 3.2 Settings

- 路径 `~/Library/Application Support/jui-jspace/settings.properties`（java.util.Properties）。
- 8 项真实生效：外观(follow/light/dark)、默认布局(1/2/2x2)、新标签页位置(home/current)、
  显示隐藏文件、文件夹置顶、列表密度(comfort/compact)、默认排序键+方向、启动恢复上次工作区。
- 「启动恢复」为真时退出前保存各面板各标签路径与视图模式，下次启动还原。

## 4. 设置窗口（第二个 Window）

- 工具栏「设置」或 ⌘, 打开；420×480 起，左侧栏 200 DIP。
- 左：搜索框（过滤导航项）+ 分组导航列表，每项彩色圆角贴片图标(20)+名称，
  选中项强调色圆角高亮块；分组：通用、外观、面板、标签页、书签、暂存架、传输、扩展、快捷键、关于。
- 右：分组圆角卡片（surface 底、12 DIP 圆角、组标题灰色小字），iOS 风格 toggle、
  复选框、popover 下拉；底部橙色警示文字（如「注意：以下默认选项只在新创建工作区时起作用。」）。
- 「通用」页承载 8 项真实设置（含警示行样式还原）；其余页居中灰字「此设置页在演示中未实现」。
- 关闭即隐藏（状态保留）；设置变更即时生效并写盘。

## 6. 框架扩展（本设计唯一框架改动）

1. `Ui.splitVertical(Context, DoubleRef/FloatRef firstHeight, Runnable first, Runnable second)`：
   将现有 `split` 参数化为方向——dragX→dragY、宽→高、`Cursor.RESIZE_EW`→`RESIZE_NS`、
   键 ←→→↑↓；补 `SplitVerticalTest`（拖动、键盘、最小高度、alloc 场景纳入既有 alloc 门槛）。
2. （条件触发）`Theme` 注入自定义色板的能力，仅当现状不支持时。

## 7. 非目标（本轮明确不做）

拖拽（面板间/侧栏/桌面）、废纸篓还原与清空、压缩/解压、远程/FTP/SMB、预览面板与 QuickLook、
Spotlight 内容搜索（仅名称过滤）、多选（⌘/⇧）、WatchService 自动刷新（⌘R 手动）、
访达标签联动、暂存架功能、传输队列窗口、多工作区、RTL、Windows 平台。

## 9. 风险与对策

| 风险 | 对策 |
|---|---|
| 后台线程→主线程发布路径不熟 | 照抄 notes-vault 的虚拟线程扫描+主线程发布模式 |
| native image 无 AWT | 打开文件用 `/usr/bin/open`，不引 Desktop |
| 图标网格行内项数随窗口宽变化 | key 用条目下标而非 (r,c)，list 行数随宽度重算 |
| 大目录性能 | 列表/网格都走 Ui.list 虚拟化；扫描只取直接子项 |
| Theme 不支持自定义色板 | §6 条件扩展；先验证再动手 |
| 删除/移动真实用户文件的风险 | 手动验收只用临时目录 fixture；删除一律 modal 确认 |
