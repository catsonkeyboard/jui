## 二、机制裁定（对照 MyGO 的决策）

1. **覆盖层**：MyGO 有独立的 overlay 根；j-ui 不加新的树根。`modal`/`popover` 返回的是**普通元素**，其内容作为 absolute 子元素建于调用处——paint 已保证 absolute 后画、后者在上（`Paint.java:71`），命中取 paint 序最后一个（`HitList.chain` 从后往前），构建在视图末尾的覆盖层天然盖住并挡住先构建的内容。`NotesDemo` 的视图按「外壳 → modal/popover 收尾」的顺序构建。
2. **split**（`split.go:36`）：
   - 行；两个 pane 以 1 DIP 分隔线相接，各自 `clip()`；`firstWidth` 是第一 pane 的宽。
   - 分隔线可聚焦（Tab 顺序在两 pane 之间），`←`/`→` 每次 8 DIP。
   - 拖动手柄是 absolute 子元素，横跨分隔线两侧各 4 DIP，指针 `ResizeEW`；按下即聚焦分隔线，只有位移才改宽度。
   - 夹取 `clamp(v, minPane, total−1−minPane)`，`minPane=40`（MyGO 代码是 10，文档写 40 且不一致；j-ui 取 40，侧栏场景更实际）。空间不足时第一 pane 让位（按 `min(firstWidth, minPane)` 布局），`firstWidth` 不改，空间回来即恢复。
   - `changed()` 报告；悬停或按住时分隔线变强调色。
   - 拖动用现有 `dragX()`（指针捕获已是 M2 行为）；无 MyGO 的 `Dragged`/无障碍 range。
3. **modal**（`base.go:473`、`widgets.go:595`）：
   - `open` 为假：元素照常返回但 `invisible()`，内容不构建（j-ui 不返回 null）。
   - 打开：absolute 铺满的背景（黑 40%），`center()`；面板 `padding(20).gap(12).radius(10)`、surface 背景、阴影、`maxWidth(窗口−40)`、`maxHeight(窗口−40)`。宽度取链上的显式宽度（如 6.15 的 `.width(560)`），否则收紧内容。
   - 点背景或 `Esc` 关闭；`dismissed()` 在关闭的那一遍报告一次。
   - **焦点圈定**：modal 打开期间 Tab 只在其中循环；打开时记住此前焦点，关闭后还回去。这是本计划唯一的引擎级改动（`Input.moveFocus` 尊重最内层打开的 modal；同 MyGO `flagModal` 的意图）。
   - `Esc` 由 modal 自己处理：它是窗口里最后构建的层，`Esc` 先于应用快捷键给最上层打开的 modal。
4. **popover**（`base.go:431`、`widgets.go:611`、`element.go:934`）：
   - 面板挂在 anchor **下方、起点对齐**；`minWidth` = anchor 宽；与 anchor 的间距用 margin（下方时为 top margin，翻上方时换边）。
   - 溢出窗口时翻到 anchor 上方，仍溢出则沿 anchor 方向平移入窗；两次都放不下取溢出小者。
   - 定位用 anchor 上一帧的窗口坐标（`Element.bounds()`）；anchor 本帧消失则关闭。
   - 点面板外（anchor 自身算内）或 `Esc` 关闭；`dismissed()` 报告；面板内按下不关闭。无背景层（同 MyGO 非 modal 裁定）。
5. **tabs**（`base.go:187`、`tabs.go:15`）：
   - 行、`gap(4)`；每个 tab 是可聚焦的行：点击选择；选中项文字色、`fontWeight(600)`、底部 2 DIP 圆头强调条；未选中 hover 变文字色；焦点环。
   - 方向键/↑/↓/Home/End 在有焦点时移动选择，焦点跟随（仅键盘移动时显示焦点环）；`selected` 夹到 `[0, n−1]`；`changed()` 报告。
6. **应用菜单**（`app.go:331`、`menu.go`）：
   - MyGO 是 `SetMenu(静态模板)` + 角色。j-ui 裁定：**沿用计划三的会话模型提升到菜单栏**——`App.menu(bar -> {...})` 注册一次；NSMenu 栏一次装好标题，各子菜单在即将展开时（`menuNeedsUpdate:`）和选择后重跑 builder，`chosen()` 读取结果，取消不跑。与 `contextMenu` 同一套 `MenuState` 会话保护。
   - `bar.submenu("文件")`、`item(标签, Shortcut)`、`separator()`、`disabled`、`checked`、`editItems()`（挂标准 Edit 项，绑定打开时的输入框，同右键菜单）。
   - 快捷键经菜单栏的 key equivalent 触发（不打开菜单也生效），选择后 `chosen()` 报告并请求出帧；**应用不要再为同一键注册 `c.shortcut`**（会双发），文档写明。
   - 标题本地化不做（英文标题）；Quit 项保留在应用菜单。

## 三、与 MyGO 的差异（预先记录）

- split 的 minPane 40（MyGO 10）、箭头步长 8（2.5）、手柄 8 DIP 宽（MyGO ~1.5）：MyGO 注释与实现不一致，按可用性取值。
- modal/popover 无独立 overlay 根，靠构建顺序 + absolute； popover 的 RTL、`AttachTo` 任意锚点组合不做，只有下方/上方两种（锚点组合是 MyGO 给徽标等用的通用机制，外壳用不到）。
- tabs 无 `TabsBase`/`Tab(i)` 拆分；`FocusGroup` 无对应物，焦点跟随用局部状态实现。
- 应用菜单不用角色系统；编辑项复用计划三的 `editItems`。
