# 统一 Notes 示例：实现与验证

日期：2026-11-01。分支codex/unified-notes-demo，基线0adcf91。用户要求Notes与NotesMotion整合，并选择默认跟随系统明暗、保留三栏样式。未合并、未推送，.idea及其他工作树未改。

## 实现

- NotesDemo持有唯一目录、已打开标签、分组与筛选、预览内容和菜单动作；NotesWorkspace负责三栏布局、颜色、图标与动画。删除独立NotesMotionDemo；build.sh将NotesMotion映射到Notes，保留旧运行命令。
- 1万条笔记使用虚拟化96DIP卡片；按标题缓存筛选；新增笔记与菜单/分组/标签共享身份，不复制成另一份Sheet。
- 默认随系统明暗，未强制Dark Aqua。标题使用Times New Roman衬线排版，正文保留原富文本/磁盘首篇正文节点。
- 侧栏动画可反向，关闭后编辑区保留恢复按钮。分割条8DIP命中区、1DIP布局宽度，随折叠归零；120DIP以下暂禁拖动，编辑区保留160DIP，窄窗口放大后偏好宽度恢复。
- 保留搜索/IME、tabs、modal、popover、应用菜单、vault/forTools/首帧测量；自动演示与缩短过渡通过同一Notes入口。命令面板/新建菜单没有重复注册窗口快捷键。

## 实施裁定

1. 沿用现有检出创建特性分支，保留.idea及其他工作树。代价：未额外创建第二工作树。
2. 一个目录/标签/分组模型，保留只读富文本正文，衬线字用于预览标题；不新增框架字体API。代价：不再展示另一份独立Lorem正文目录。
3. 可折叠三栏使用公共Element.dragX/InputHandler组合分割条，不改core split约束；拖动在完全展开且宽度足够时启用。代价：示例分割条是组合控件，最窄120DIP偏好宽度有别于底层split。
4. Last 7 Days保留演示分类，检索维持Notes约定的标题过滤；初始笔记未分组，分组用于新建笔记。Inbox显示未分组、All包含分组笔记；代价：真实时间/全文索引仍未实现。
5. 分割条位于布局流中，预留160DIP编辑区；窄宽度可压缩实际侧栏，扩大后恢复偏好。代价：窗口很窄时卡片可能被裁剪，用户可隐藏导航。
6. 基准根据notes-list实际边界滚动，96DIP卡片每步64DIP，仍验证超过1000行与相同时间/分配限制。代价：本轮滚动夹具与旧32DIP行/24DIP步长不同，不宣称同负载加速倍数。
7. App.menu绑定实例；原来没有处理的“关闭窗口”项改为明确的“关闭标签页”(Cmd-W)，共用closeTab。关闭窗口/退出仍使用系统控件。代价：菜单命名明确了标签而非窗口关闭语义。
